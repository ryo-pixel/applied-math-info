## Morse Decomposition of a One-Dimensional Dynamical System

This figure illustrates the Morse decomposition of the one-dimensional dynamical system

\[
\dot{x} = x - x^3
\]

The system has three equilibrium points:

- M- (-1): Stable equilibrium
- M0 (0): Unstable equilibrium
- M+ (1): Stable equilibrium

The arrows indicate the possible transitions between Morse sets. A trajectory starting near the unstable equilibrium \(M0\) eventually moves toward one of the two stable equilibria, \(M-\) or \(M+\).

This graph summarizes the qualitative behavior of the dynamical system by representing invariant sets (Morse sets) and the possible flow between them.
