# Smart Home Example of Integrated Information Theory (IIT)

## Overview

This project illustrates an example of Integrated Information Theory (IIT) using a smart home system.

Two systems are compared:

- Independent System: The light is controlled only by a motion sensor.
- Integrated System: The light is controlled by both a motion sensor and a door sensor.

The integrated system combines information from multiple sensors, representing a higher level of information integration.

Note: The Φ (phi) values shown in the graph are illustrative only. They are not calculated using the mathematical formulation of IIT.

## Files

- plot.py : Displays a bar chart comparing the two systems.
- README.md : Project description.

## Requirements

- Python 3
- matplotlib

## How to Run

```bash
python plot.py
```

## Output

The program displays a bar chart comparing the illustrative integrated information (Φ) of the two smart home systems.
